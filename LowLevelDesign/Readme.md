# Composition
use references to other objects rather than inheriting from a parent class.
Like Car has an Engine. Car is not derived from engine.

Composition is often preferred over Inheritance.

# Pragmatism over Pattern worship
Pattern worship - design patterns are absolute laws.
Pragmatism - Simplest thing that could possibly work, scale and easily be changed later.

Like: starting out with Pragmatic Monolith rather than microservice and only splitting a component into its own service if it suffers to scale, perform.
